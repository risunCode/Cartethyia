# Filter Rules archive

The legacy outbound-text sanitizer page and runtime pipeline were removed from the active Cartethyia runtime before the current release line. This file preserves the historical link referenced by older changelog entries; it is not an active configuration or migration surface.

Current request validation and safety boundaries are implemented through the active protocol normalizers, request limits, SSRF guard, redirect policy, bounded body/stream readers, provider capability checks, and sanitized error envelopes.
