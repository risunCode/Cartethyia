# Commit notes — 1.0.7-alpha

## Conventional Commit subject

```text
release: 1.0.7-alpha — expand OAuth providers, proxy operations, and dashboard UX
```

## Context

The diff from the `1.0.6-alpha` release line is broader than a single Kiro/customization change. Cartethyia 1.0.7-alpha adds the OAuth/tokenkeeper subsystem, multiple provider adapters, outbound proxy management, 9router account compatibility, public share-state handling, quota cooldowns, responsive dashboard work, persistence/runtime fixes, and community/release documentation.

## Changes

1. OAuth and provider integrations
   - Added shared OAuth credential bundles, token leasing, refresh handling, health state, account lifecycle actions, callback/import routes, and tokenkeeper single-flight behavior.
   - Added Codex, Anthropic OAuth, Cline, Grok CLI, Google Antigravity, and Kiro provider adapters, catalogs, route metadata, icons, request translation, usage/reasoning separation, and protocol tests.
   - Added Kiro AWS Builder ID/IAM Identity Center device authorization, refresh-token import, regional refresh, profile metadata, Kiro model catalog, `kiro/<model>` routing, and AWS EventStream decoding.
   - Added Antigravity cloud-code project metadata, Gemini/Claude model mappings, web-search translation, endpoint fallback, and robust SSE decoding.
   - Added provider model tests and account actions to the dashboard; fixed Grok OAuth button dispatch.

2. Outbound proxy operations
   - Added HTTP/HTTPS and SOCKS5 proxy adapters with proxy-aware fetch, raw socket tunneling for HTTP/2 paths, and provider dispatch integration.
   - Added console proxy CRUD, URL batch import, protocol detection, relay detection, priority/active controls, failover handling, and dashboard management.
   - Kept custom-provider SSRF protection active on top of proxy routing.

3. Account import, backup, and persistence
   - Added 9router-compatible backup detection/import with safe token extraction and HTML/invalid-token rejection.
   - Extended backup/restore for provider accounts, share links, OAuth credentials, one-time budgets, custom words, and current runtime/config data boundaries.
   - Kept configuration SQLite and runtime telemetry SQLite separate, with account health/quota metadata and retention behavior aligned to `DATA_DIR` conventions.

4. API keys and public share pages
   - Added/expanded API-key budgets, one-time token reservation/settlement, ACL/model selection, share links, copy actions, custom words, usage visibility, and key lifecycle behavior.
   - Disabled share links now return an explicit disabled state without exposing credentials, usage, or allowed models; invalid links remain `404`.
   - Fixed qualified alias/model ACL matching and duplicate alias presentation.

5. Dashboard and user experience
   - Added custom background upload behind frosted-glass surfaces.
   - Added optimized seasonal lock effects with responsive particle counts, reduced-motion support, hidden-tab pausing, frequency control, custom item upload, image shrinking, and recommended rendered size.
   - Added custom-provider select-all and bulk-delete controls with confirmation.
   - Refined provider detail/OAuth/account/model-test screens, settings/import flows, usage, login, Model Studio, proxy/request pages, navigation icons, and responsive desktop/mobile layouts.

6. Quota, performance, and protocol fixes
   - Removed Grok CLI billing quota fetching and its dashboard quota entry.
   - Added a 15-minute per-account quota cooldown and sweep; kept token refresh expiry-driven and relaxed quota dashboard refresh to five minutes.
   - Added Antigravity CRLF SSE support and final-frame flushing so model tests return visible sample text.
   - Preserved proxy failover for candidate-specific upstream errors and corrected provider/account health updates after model-test failures.
   - Continued the config/runtime caching, write-behind, bounded-state, request-tracking, and dashboard rendering performance work from the current release diff.

7. Community and release documentation
   - Bumped root and dashboard package versions to `1.0.7-alpha`.
   - Updated `README.md`, `CHANGELOG.md`, and `AGENTS.md`.
   - Added `CODE_OF_CONDUCT.md` and `.github/PULL_REQUEST_TEMPLATE.md`.
   - Added these complete release notes at `docs/commit-notes/1.0.7.md`.
