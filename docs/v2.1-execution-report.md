## 1. OVERVIEW — Apa yang udah dikerjakan

### 1.1 Konteks singkat

Cartethyia = **Go daemon** (LLM proxy router: client ingress `/v1` + `/v1beta`, console plane, share links, telemetry) + **dashboard SolidJS** (console admin SPA + landing). v2.1 adalah **breaking release yang disengaja**: owner memutuskan tidak ada backward compatibility, tidak ada alias, tidak ada fallback — surface lama dibuang, bukan didiamkan.

Eksekusi dilakukan 2026-08-16 oleh main agent + 6 delegate agent mengikuti workstreams WS0–WS7 di plan doc, dengan Postgres (Laragon) + Redis lokal dalam kondisi **fresh reset** (drop database + FLUSHALL, owner-authorized).

### 1.2 Enam perubahan besar

1. **Surface console pindah total: `/v2/admin/*` → `/console/*`.**
   Prefix `/v2/admin` dihapus di daemon, dashboard, proxy, dan docs. Path di-collapse (`/v2/admin/console/logs` → `/console/logs`, bukan `/console/console/logs`). Panggilan ke prefix lama sekarang **404**, dan itu dikunci oleh regression guard di `transport-contract.test.ts` dan di `scripts/validate-fullstack.ts`.

2. **Auth jadi cookie-only + stateless JWT.**
   Session transport sekarang cuma cookie `cartethyia_session` (HttpOnly, same-origin). `X-Session-Id` header dan `?sessionId=` query fallback **dihapus** dari `readSessionID` (`daemon/internal/server/admin/auth.go`). JWT HS256 stateless yang di-bind ke `password_version` — ganti password = semua session mati. Password hashing argon2id (PHC). Bootstrap console password dari env `CONSOLE_PASSWORD` di-seed **lazy saat login pertama**, jadi tidak ada lagi kejadian "stale hash dari DB lama bikin login 401".

3. **Satu port publik: 12800.**
   Owner directive: **web dan API v1 harus sama-sama di 12800.** Di compose, nginx jadi single edge `"12800:80"` yang serve static SPA dan proxy-kan `/console/`, `/v1/`, `/v1beta/`, `/internal/`, dan `/share/*/data|stream` ke service internal; publish port daemon ke host **dihapus**. Di dev lokal: daemon listen `:12800` langsung, vite :5173 mem-proxy `/console`, `/v1`, `/internal`, dan `/share` (dengan `bypass` — hanya `*/data`, `*/stream`, `setup/*` yang diteruskan ke daemon, sisanya fall-through ke SPA).

4. **~30 orphan route daemon dipangkas + dead code dashboard dimusnahkan.**
   Route family yang dibunuh: `keys`, `custom-providers`, `proxies` (8 route), `proxy-settings`, `web-search-routing`, `tools` (4), `backups` (4), `quota/refresh`, `catalog/models`, `console/web-request`, `DELETE settings`, `accounts/:id/revoke`, `accounts/:id/oauth-status` — beserta layer service/repository-nya yang tidak dipakai tempat lain, plus package `daemon/internal/database/backup` (13 file). Di dashboard: ~28 file frontend mati dihapus (dead Bearer stack, composables, components lama). Prinsipnya: **dead code di-delete, bukan di-disable.** Yang tersisa di contract matrix: **26 route** (`dashboard/src/lib/console-routes.ts`), daemon admin tree punya **23 handler registration**, selisih method+path yang tidak dipakai UI dicatat eksplisit di `KNOWN_UNCOVERED_DAEMON_ROUTES` (7 entri, lihat §4 P2-4).

5. **Aux server (Bun :8787) dipisah databasenya.**
   Dashboard punya backend kecil untuk `/internal/health` (pg) dan `/internal/logs` (sqlite sink untuk error-reporter browser). Ternyata migrasi dashboard dan schema daemon **sama-sama mendefinisikan tabel `api_keys` dan `share_links` dengan bentuk berbeda** — kalau satu DB, `CREATE TABLE IF NOT EXISTS` akan silently skip lalu insert meledak. Maka aux server sekarang wajib jalan di DB sendiri: `cartethyia_dashboard` (lokal) / service `dashboard-audit` + init script `docker/postgres-init/01-create-dashboard-db.sql` (compose). Bonus hardening: directory sqlite di-bootstrap otomatis (`mkdirSync` parent), dan kalau migrasi gagal server **refuse to serve** (`exit 1`), bukan jalan di setengah schema.

6. **SSE diberi heartbeat + proxy behavior yang benar.**
   Dua stream console (`/console/telemetry/in-flight/stream`, `/console/logs/stream`) sekarang mengirim komentar `: ping` setiap `adminStreamTick` (2s) saat idle, supaya koneksi tidak diputus proxy/load balancer. nginx: `proxy_buffering off; proxy_read_timeout 300s`. Stream juga dedupe snapshot yang tidak berubah. Auth SSE lewat cookie sama seperti request biasa (`?token=` yang diabaikan daemon sudah dihapus dari `src/lib/sse.ts`).

## 7. Lore & Quirks — supaya tidak kepleset lagi

- **Solid + props destructuring = reactivity mati.** `ProgressBar` pernah jadi kasus — selalu akses via `props.x` di dalam getter/fx.
- **`createResource` melempar kalau error** — memo yang membaca `resource()` tanpa guard `resource.error` akan crash halaman (fix di Usage/Providers/Quota/Settings/LogHistory).
- **TanStack solid-virtual `count` harus object getter** `get count() {...}` — arrow function `count: () => n` tidak dipanggil mergeProps-nya → `RangeError: Invalid array length`.
- **Vite proxy men-lowercase header** — `Set-Cookie` jadi `set-cookie`; script cookie-extraction harus `grep -i`.
- **Collision tabel `api_keys`/`share_links`** antara migrasi daemon dan dashboard — inilah alasan aux server WAJIB DB terpisah. Jangan pernah satu-kan.
- **Path collapse console**: `/v2/admin/console/X` → `/console/X` (bukan `/console/console/X`).
- **Windows/Git Bash**: file bernama `NUL` meng-block `git add` (`rm -f NUL` works di MSYS); kill proses pakai `taskkill.exe //F //PID <pid>` (double slash).
- **Tailwind v4** via plugin `@tailwindcss/vite` — tidak perlu `postcss.config.js`/`tailwind.config.js` (sudah tidak ada, jangan dibuat lagi).
- **`daemon/cover.out`** tidak di-ignore dengan nama literal, tapi oleh pattern `daemon/*.out` di `.gitignore`.
