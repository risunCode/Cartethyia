# Cartethyia v2.1 — Console Surface & Cleanup Plan

**Status:** PROPOSED — awaiting owner validation
**Branch:** `go-rewrite` · **Date:** 2026-08-16
**Sources:** deep-scan audit 2026-08-16 (contract audit, dashboard structure audit, E2E smoke, full test suites)

---

## 0. Principles (locked by owner)

1. **v2.1 is a breaking release.** No backward compatibility, no aliases, no fallback paths, no legacy shims.
2. **Console API lives directly at `/console/*` on the daemon.** The `/v2/admin` prefix is deleted everywhere.
3. Client ingress `/v1/*`, `/v1beta/*`, public `/share/*`, `/health`, `/metrics` are **unchanged**.
4. **Clean repo:** dead code is deleted, not disabled. Orphan daemon routes are trimmed.
5. Local verification against real Postgres (Laragon) + Redis. **Database may be dropped for a fresh state** (owner-authorized).

## 2. Route Map — old → new

Daemon mount: `daemon/internal/server/admin/admin.go` — `mux.Handle("/v2/admin/", scopedAdmin(...))` → `mux.Handle("/console/", ...)`; also the `notReady("v2 admin API")` guard in `daemon/internal/server/router.go:148`.

Path collapse rule: `/v2/admin/console/*` becomes `/console/*` directly (no double "console"): `/v2/admin/console/logs` → `/console/logs`.

| Old (`/v2/admin/...`) | New (`/console/...`) | Notes |
|---|---|---|
| `POST auth/login` | `POST /console/auth/login` | only unauthenticated route |
| `POST auth/logout`, `GET auth/session`, `POST auth/refresh` | same shape | |
| `auth/oauth/*` (start, sessions, refresh, complete, cancel) | `/console/auth/oauth/*` | kept intact (product capability) |
| `GET dashboard` | `GET /console/dashboard` | |
| `GET telemetry/{overview,requests,errors,upstream,usage,clients}` | same shape | |
| `GET telemetry/in-flight/stream` (SSE) | same shape | |
| `GET console/logs`, `GET console/logs/stream` (SSE) | `GET /console/logs`, `GET /console/logs/stream` | **collapsed** |
| `POST console/web-request` | — | **killed** (WS4) |
| `GET/PATCH/POST settings` | same shape | |
| `DELETE settings` | — | **killed** (WS4) |
| `accounts`, `accounts/:id` (GET/POST/PATCH/DELETE), `accounts/:id/quota` (GET/POST) | same shape | refresh = `POST /console/accounts/:id/quota` |
| `providers/:id/accounts`, `providers/:id/accounts/batch`, `providers/:id/accounts/:accountId` | same shape | |
| `GET catalog/providers` | same shape | |
| `keys`, `keys/:id`; `custom-providers`, `custom-providers/:id`; `proxies` family (8); `proxy-settings`; `web-search-routing`; `tools` family (4); `backups` family (4); `quota/refresh`; `catalog/models`; `accounts/:id/revoke`; `accounts/:id/oauth-status` | — | **killed** (WS4 — full list in §6) |

**Session transport (breaking):** cookie `cartethyia_session` ONLY. Remove the `X-Session-Id` header and `?sessionId=` query fallbacks from `readSessionID` (`daemon/internal/server/admin/auth.go`). SSE authenticates via same-origin cookie.

12. `docker-compose.yml`: add `dashboard-audit` service (dashboard image, `bun run server`, env `CARTETHYIA_DASHBOARD_DATABASE_URL`, `CARTETHYIA_DASHBOARD_SQLITE_PATH`, depends_on postgres) so the existing nginx `/internal/` rule resolves.
