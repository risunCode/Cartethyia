# Skill self-improvement

Update this skill only after a repeated failure, rejected change, or newly found
drift class.

1. Search existing references first; extend the closest owner instead of adding a competing skill.
2. Keep guidance procedural: state the trigger, required check, failure mode, and evidence.
3. Verify every cited path, symbol, command, and export before writing it.
4. Remove guidance that no longer matches the repository.

The skill should teach a reusable decision or verification step, not preserve a
one-off implementation note.
