# Cartethyia Code of Conduct

## Purpose

Cartethyia is a self-hosted, security-sensitive infrastructure project. This Code of Conduct defines the behavior expected in project repositories, issue trackers, pull requests, discussions, chat spaces, and project-related events.

It applies to maintainers, contributors, reviewers, users, service operators, and anyone representing the project.

## Expected behavior

Participants MUST:

- Communicate respectfully and assume good faith while remaining evidence-driven.
- Keep technical criticism focused on code, behavior, security impact, and project decisions—not on people.
- Provide enough context to reproduce a problem and accept correction when evidence changes.
- Respect different experience levels, identities, cultures, languages, and working styles.
- Protect private information. Never publish API keys, OAuth tokens, passwords, cookies, database files, private logs, or personal data.
- Follow the repository's security, persistence, and deployment conventions.
- Disclose conflicts of interest and avoid abusing maintainer or operator access.
- Use private reporting for security vulnerabilities and sensitive incidents.

## Unacceptable behavior

The following behavior is prohibited:

- Harassment, discrimination, hate speech, threats, stalking, intimidation, or targeted personal attacks.
- Sexualized comments or unwanted romantic/sexual attention.
- Doxxing, credential theft, publishing private information, or exposing secrets.
- Deliberate disruption, spam, impersonation, brigading, or bad-faith manipulation of project processes.
- Encouraging unauthorized access, abuse of provider accounts, bypassing ACLs, or unsafe handling of credentials.
- Submitting malicious code, hidden telemetry, supply-chain changes, or unrelated destructive changes without disclosure.
- Retaliating against someone who reports a concern or participates in an investigation.

## Enforcement

Project maintainers may remove content, request changes, restrict participation, revoke project access, or permanently ban an account. Responses will be proportionate to the behavior and the available evidence. Maintainers may act immediately when there is a credible risk to people, credentials, infrastructure, or the project.

Maintainers will:

1. Acknowledge a report when practical.
2. Preserve relevant evidence and limit access to people who need it.
3. Give the reported participant an opportunity to respond when doing so is safe.
4. Decide and document an appropriate action.
5. Communicate the outcome to the reporter where permitted, without exposing confidential details.

## Reporting

For conduct concerns, contact the maintainers privately through the Cartethyia Discord community: <https://discord.gg/zFcNPJM6qM>. Do not include secrets in a report; redact tokens, credentials, hostnames, and private user data.

For security vulnerabilities, do **not** open a public issue or post exploit details in chat. Use the repository's private security reporting channel or contact the maintainers privately through Discord and request a security handoff. Include reproduction steps, affected versions, impact, and a safe mitigation when available.

Reports will be handled confidentially as far as practical. Good-faith reports are protected from retaliation.

## Scope and appeals

This Code of Conduct applies both online and offline when a participant is acting on behalf of Cartethyia or the conduct affects the project community. A participant may privately request a review of an enforcement decision with additional evidence; maintainers may uphold, modify, or reverse the decision.
